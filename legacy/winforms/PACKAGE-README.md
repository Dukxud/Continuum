# Codex Resume Scheduler — legacy Windows Forms preview

Keep the complete extracted package together. To open the app from its root directory:

```powershell
wscript.exe .\legacy\winforms\Start-Codex-Scheduler.vbs
```

Windows, PowerShell 7 in its standard installation location, Node.js, Git, and an installed, signed-in npm Codex CLI are required. This preview is unsigned. Closing the app does not cancel jobs already registered with Windows Task Scheduler.

This package contains the older Windows Forms interface. The current Continuum application uses Flutter. See the [project repository](https://github.com/Dukxud/Continuum) for current source and documentation.
